# 分析检查清单

## A. 盘前：先定「能不能做」

1. 大盘/板块处于什么环境？（主线/轮动/退潮）
2. 目标股属于哪个**主线题材**？逻辑级别（产业趋势 > 政策 > 事件 > 纯情绪）？
3. 位置：距 250 日高点/低点多少？处于低位、中继还是高位？
4. 均线：移动平均带是缠绕、多头排列还是空头排列？
5. BIAS60 是多少？是否进入 -20%/-30% 或 +30%/+50%/+100% 区间？
6. 近 5 日是否有异动（涨停/跌停/缺口/长上影/历史天量）？

> 若 1—3 任一为空（无主线、位置高位），直接降低仓位或放弃。

## B. 模型匹配：逐条打勾

对候选模型（见 `models.md`）逐条填 ✅/❌：

- [ ] 要素一（异动价）成立
- [ ] 要素二（异动量）成立
- [ ] 要素三（均线结构/修正结构）成立
- [ ] 位置条件成立（低位/中继，非高位）
- [ ] 时间条件成立（间隔、平台时长、连阳数量）
- [ ] 无失效信号（缺口回补、跌破关键均线、量价背离）

**判定**：6/6 = 标准版；4—5 = 弱化版（降仓）；≤3 = 不成立。

## C. 买点与执行

- 买点类型：突破 / 回踩 / 乖离 / 反包
- 触发条件是否可量化（价格、量能、时间）？
- 首笔仓位？加仓条件？单票上限是否满足？
- 止损位（结构位 / 12% / 中期均线组，取先到者）？
- 止盈计划（分批价位或均线）？

## D. 风险自检（全部通过才下单）

- [ ] 单票仓位 ≤ 上限（散户 20%）
- [ ] 组合板块数 3—5 个
- [ ] 总仓位与市况匹配（退潮期 ≤ 30%）
- [ ] 止损位明确且不超过 -12%
- [ ] 不处于「亏损加仓」状态
- [ ] 若模型失效，退出路径清晰（不是「再等等」）

## E. 盘后复盘

1. 今天是否按计划执行？偏差原因？
2. 模型命中/失效的原因（位置、量能、题材级别）？
3. 止损是否触发？是否执行？
4. 记录到交易日志（模板见 `assets/trade-plan.md`）。
5. 每周统计：胜率、盈亏比、最大回撤、模型命中率。

## F. 快速否决项（出现任一，不做）

- 位置在高位且 BIAS60 > 50%；
- 只有形态没有量（缩量假突破）；
- 缺口已回补仍按「真空反转平台」做多；
- 跌破中期均线组仍按「模型仍有效」持有；
- 无止损计划的交易。
