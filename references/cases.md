## 基本面案例类（好产品属性）

| 属性 | 案例 | 要点 |
|---|---|---|
| to C | 茅台、五粮液、爱尔眼科、泡泡玛特、老铺黄金、蜜雪冰城 | 用户基数大、定价权、现金流好 |
| to B | 苹果链（立讯精密、歌尔股份） | 下游是 to C，可做品类扩张 |
| 属性切换 | 东方财富 vs 同花顺；高能环境 | to B→to C、to G→to B 带来重估 |
| 产品通胀 | 高端白酒、老铺黄金（约 25 倍）、PCB/光模块 | 价格中枢上行 |
| 产品通缩 | 汇顶科技 | 指纹芯片 10 美元→3→1 美元以下，股价跌九成 |
| 后天通胀 | 重庆啤酒（约 20 倍）、海螺水泥 | 竞争格局改善、价格中枢上行 |
| 渗透率 | 智能手机/苹果链、TWS、EPS（耐世特）、扫地机器人（科沃斯、石头科技） | 10%—20% 临界后加速 |
| 渗透率（供给风险） | 培育钻石 | 需求爆发但扩产过快，价格战 |
| 消费属性 | 飞鹤（六倍股）、海天味业、茅台 | 三者分离 + 高频 |
| 差异化 | 模拟芯片（盛邦等）vs 汇顶；隔膜（恩捷股份）；牧原股份 | 差异化=定价权；良率低可能是壁垒 |
| 标准化→差异化 | PCB、光模块、定制家居（索菲亚 10 倍） | 属性迁移带来重估 |
