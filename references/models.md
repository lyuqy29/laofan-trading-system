# 九大交易模型（完整要素与执行规则）

> 来源：老樊「微产品论」课程第 07、08、09、11、12、13 讲。要素与阈值以课程原话为准；**带「※」的量化口径是本 skill 为便于执行补充的操作定义，课程本身以经验描述为主。**

## 0. 通用框架

任何模型都由四类要素组合而成，缺一即降级：

| 要素 | 只看「异动」 | 常见形态 |
|---|---|---|
| 价 | 异动价 | 涨停、跌停、跳空缺口、极值长上影/长下影、涨停破板 |
| 量 | 异动量 | 倍量（≥前日 2 倍）、历史天量、久违堆量、极致缩量 |
| 时 | 时间结构 | 底部平台 ≥3 个月、两次涨停间隔 ≤1 个月、连阳 ≥7 根 |
| 空 | 空间结构 | 乖离率、累计涨幅、回撤幅度、缺口大小、密集区距离 |

※ 量化口径：
- **倍量**：当日成交量 ≥ 前一交易日 × 2（量比 ≥ 2）。
- **历史天量**：当日成交量 ≥ 近 120 个交易日最大成交量的 90%，或创近一年新高。
- **极致缩量**：当日量 ≤ 近 20 日最小量 × 1.2，或 ≤ 5 日均量的 50%。
- **长上影**：上影线长度 ≥ 实体 2 倍，且上影幅度 ≥ 3%；「极值长上影」指触及涨停后回落 ≥5%。
- **乖离率**：BIAS60 =（收盘价 − MA60）/ MA60 × 100%。
- **位置**：低位 = 距 250 日最高点跌幅 ≥40%，或长期横盘平台下沿；高位 = 距 250 日最低点涨幅 ≥100% 且 BIAS60 > 30%；中继 = 上升趋势中回踩中期均线组。

## 2. ① 上影反攻模型

**定位**：识别主力用「涨停破板 + 长上影」完成洗盘后再度进攻。

**要素**
1. **异动价**：涨停板破板（炸板），留下极值长上影线；出现在底部区间或历史顶部区间均可。
2. **异动量**：当日或随后出现历史级别天量、久违的堆量；筹码峰由分散转为**单峰密集**。
3. **均线**：移动平均带由缠绕/空头转为**多头排列**（短期组 5/8/13 在中期组 55/60/65 上方），随后回踩中期均线组横盘、**极致缩量**，一根**放量中阳线**企稳。

**买点**
- 中阳线站上短期均线组、或放量突破长上影最高点 → 首笔；
- 回踩中期均线组不破再放量 → 加仓。

**止损**：长上影线最低点下方 2%—3%，或跌破中期均线组。

**失效**：长上影后 3 个交易日内不涨反跌破短期均线组；天量后量能持续萎缩且股价横盘下移。

**案例**：昊志机电（2023-05-18 涨停破板长上影 + 堆量 + 均线转多）；银轮股份（2024 末—2025，历史顶部区间同样成立）；银宝股份（题材股）。

## 3. ② n 式倍量双涨停模型

**定位**：低位反转信号。多头第一次进攻被套牢盘砸回，第二次进攻成功。

**要素**
1. **异动价 + 量**：低位第一根**倍量涨停** → 回撤 → **同一位置附近第二根倍量涨停**，两根涨停与回撤构成「n」字形对称；两次涨停间隔 **≤1 个月**；回撤最好不破第一根涨停最低价（若破，须次日立即收回）。
2. **均线**：由空头排列转为**多头排列**，趋势被真正扭转。
3. **位置**：必须在大级别下跌趋势末端/低位——位置不对直接排除。

**变形版**：涨停 + 长时间横盘（中期均线走平、股价站上均线组）+ 再涨停；实战频率高（伯特利，涨 30%+）。

**强弱分级**
- 标准版：低位大跌末端 → 最强；
- 弱性版：上涨趋势确立后的二浪震荡中枢末端（晶方科技）；
- 最弱版：A-B-C 的 B 浪反弹（常山北明仅约 20 个点，靠题材）；
- 高位同形态：**不是模型**，直接排除。

**买点**：第二根倍量涨停当日或次日；或回踩中期均线组起稳后。

**止损**：第一根涨停最低价下方 2%。

**失效**：两次涨停间隔 >1 个月；跌破首板低点且次日不收回；均线未转多。

## 4. ③ 串阳爬坡模型

**定位**：识别主力「隐蔽进场」——用连续小阳线爬坡而非涨停吸引注意。

**要素**
1. **时间 + 空间**：**>7 连阳**（9 连阳更好），阳线实体要小，**累计涨幅 ≤20%**。
2. **异动价**：串阳末端出现 **1—2 根中大阳线（接近涨停）或长上影线**，把左侧套牢盘「引出来」完成筹码置换。
3. **量 + 均线**：随后横盘震荡，**量能先放后缩**，均线彻底转多头排列；回踩中期均线组（或在其偏上方）缩量企稳、再放量涨停。

**买点**：串阳突破中期均线组后的首次回踩（缩量）→ 放量阳线；或末端换手后的再突破。

**止损**：跌破中期均线组；或串阳起点下方。

**失效**：连阳累计涨幅远超 20%（透支空间）；调整期量能不放反缩不下来；跌破中期均线组。

**案例**：中国长城（串阳 + 探路尖兵叠加）；明月镜片（AI 眼镜题材）。

---

## 5. ④ 探路尖兵模型

**定位**：股价主升的「加油站」——用涨停把股价推进密集成交区，置换套牢盘后再启动第二波。**出现频率最高，失败率也偏高。**

**要素**
1. **异动价**：**1—2 个涨停板**把股价推至密集成交区（或密集区偏上方）。
2. **异动量**：涨停/高开低走对应**历史级别巨量**，多空筹码置换充分。
3. **修正结构**：回踩中期均线组缩量震荡，或在缺口上方**强势横盘**（主动调整、不破缺口），随后放量中阳启动第二波。

**买点**：修正末端放量中阳突破；或回踩中期均线组不破。

**止损**：跌穿中期均线组减半；再跌或触及 **-12% 静态止损** 清仓（风险偏好低者弱跌破直接出局）。

**失效**：涨停后直接跌穿中期均线组；缺口被回补；横盘期持续放量下跌。

**案例**：中鼎股份（机器人关节总成）；新股上市首日巨量套牢盘（两个 20cm 涨停后震荡 1—2 个月）；凯盛科技（华为折叠屏，纯题材快涨快跌）；恒立液压（人形机器人，强势横盘型）。

## 6. ⑤ 极值反转模型

**定位**：趋势末端强势反转信号。空头在同一位置释放到极致，多头立刻夺回。

**要素**
1. **位置**：明显下行趋势，或跌幅约 **30%** 的调整段末端。
2. **异动价 + 量对称**：**跌停与涨停在同一位置对称出现**（先砸跌停、随后同位置拉涨停），或向下/向上**缺口对称**出现。
3. **关键位**：头肩底等底部结构最低点、筹码密集成交区、黄金分割位、中期均线组附近。

**买点**：涨停突破中期均线组当日；或突破后回踩中期均线组不破。

**止损**：跌停板最低点下方 2%—3%，或跌破中期均线组。

**进阶：U 型极值反转**
1. 突破大级别下降趋势线并展开一浪进攻（一浪中须含连续涨停的异动量价）；
2. 二浪回调中出现「跌停 + 同位置涨停」；
3. **重新站上跌停板价位** = 多头拿回定价权 → 主升。
案例：赛力医疗（音，AI 医疗/华为链）。

**案例**：三花智控（头肩底最低点）；福瑞股份；天风证券、锦龙股份（2024 券商行情中全板块仅此两只走出模型，天风成为领头羊）。

## 7. ⑥ 一柱擎天模型

**定位**：识别强势主力控盘（多头主力高度锁仓）。

**要素**
1. **异动量价**：**倍量涨停**，或**跳空缺口 + 涨停**。
2. **均线**：移动平均带由缠绕/空头转为**多头排列**。
3. **形态**：此后连续**中小阳线紧贴短期均线组**，沿 **30—45 度角**上行；阳线放量、阴线缩量；**不跌破短期均线组**。斜率一旦加速到 60—80 度，即进入最凌厉主升段。

**买点**：沿 5/8 日均线回踩不破时介入；加速前上车。

**止损**：跌破 13 日均线（短期组下沿）；或跌破启动涨停最低点。

**失效**：贴着均线上行时出现放量阴线跌破短期组；阳线越来越短、量能背离。

**案例**：多出现于大级别产业趋势或主流题材龙头，课程未点名固定个股。

## 8. ⑦ 仙人指路模型

**定位**：大级别底部反转，抓中期趋势。

**要素**
1. **时间**：**3 个月以上**底部震荡平台（越久越好），平台尾部**极致缩量**，均线多次粘合缠绕。
2. **异动**：一根**放量涨停**突破平台，量柱越大越好（最好是近一年历史级别量柱）。
3. **确认**：随后**回踩中期均线组**不破（右侧信号）。

**买点**：回踩中期均线组确认后；或突破当日打试仓。

**止损**：平台下沿；或回踩低点下方。

**失效**：涨停量能不足；突破后直接跌回平台；底部平台不足 3 个月（降级为普通突破）。

**与一柱擎天的区别**：仙人指路 → 长期底部平台 + 中期趋势；一柱擎天 → 短期沿均线加速。

## 9. ⑧ 筹码乖离修复模型

**定位**：掘金高确定性反弹（跌透 + 真空）。

**要素**
1. **空间**：中期下跌趋势 + 末端加速赶底，**BIAS60 ≤ -30%**（-50%～-60% 更极致，越跌透越好）。
2. **异动**：下跌末端出现**跌停**（空头极致衰竭），或反弹起步出现**涨停**（多头接管）。
3. **筹码（核心）**：底部呈**双峰密集 + 中间真空带**；股价反弹走筹码真空区（阻力最小路径），向中期均线组回归。**双峰之间筹码越少、真空越干净，反弹空间越大。**

**节奏**
- 第一段：向中期均线组回归（最确定）；
- 第二段：冲击上方高位密集峰，需要基本面/大盘外力配合，摸到高峰附近往往乏力。

**买点**：异动后止跌企稳（站上 5 日线/放量阳线）。

**止损**：跌破底部密集峰下沿。

**失效**：双峰之间筹码不干净（真空带被填满）；低位峰吸筹不足。

**案例**：阳光电源（跌一年、最大负乖离约 50%—60%、末端跌停；第一波反弹约 50 个点，属「不完美」样本）。

## 10. ⑨ 真空反转平台模型

**定位**：抄「跌不动」的强势反转。

**要素**
1. **结构**：下跌趋势中出现**下跌中继平台**（多空真实对抗），平台被**跌破后跌幅明显收敛**（空头强弩之末）。
2. **异动**：出现**跳空 + 涨停**（跳空式涨停最佳）或涨停，强势打断下跌趋势。
3. **时间换空间**：不逼空，转入横盘震荡，消化平台套牢盘与底部获利盘，**抬高市场平均成本**；短期组在上、中期组在下缠绕，最终转多头排列再拉升。

**铁律**：**缺口完全不能补**，补掉即失效；跌破平台下沿或短期组重新跌回中期组下方 → 失败。

**买点**：震荡末端、均线粘合转多、股价贴短期均线组启动时；回踩中期均线组不破再发动加仓。

**止损**：缺口下沿/平台下沿。

**案例**：光正眼科（跳空涨停型）；加易股份（音，涨停型，横盘两三周后再缺口进攻）。

## 11. 模型复刻 / 嵌套 / 共振 / 对比

- **复刻**：同一模型在短区间出现 **2—3 次** → 多头动能更强、筹码重构更充分（如两次 n 式倍量双涨停、两次上影反攻）。
- **嵌套**：不同模型在构建过程中交替叠加（上影反攻 + 探路尖兵 + 串阳爬坡）→ 攻击力最强；案例：常山北明、川发龙蟒（逼空式连板）。
- **共振**：模型买点与移动平均带买点、量价背离买点、MACD 背离买点同时出现 → 胜率最高。
- **对比**：同板块选强——回踩不破中期组的、出现模型的、股性活跃（反复出现模型）的优先；模型出现位置可作为支撑位参考。

## 12. 背离共振（提升买卖点精度）

- **量价背离**：价创新高、量不创新高（多头背离，卖点）；价创新低、量反而放大（空头背离，买点）。
- **MACD 四重背离**（空头）：①线背离（DIF/DEA 不创新低）②交叉点背离（金叉点抬高）③柱背离（绿柱明显缩小）④周期背离（日线 + 周线同背离）。多头背离对称，且须发生在零轴上方。
- **黄金抄底法则**：移动平均带买点 + 量价空头背离 + MACD 四重背离 = 三重共振。
- **黄金逃顶法则**：乖离卖点 + 量价多头背离 + MACD 多头背离 = 共振。

## 13. 常见误用（必须检查）

1. 只数「两个涨停」，忽略两次都要倍量、忽略均线必须转向；
2. 把高位同形态当模型（位置错 → 全部作废）；
3. 在 B 浪反弹里做「最弱版」，把小打小闹当主升；
4. 串阳把「连续大阳、累计涨幅超 20%」当爬坡；
5. 真空反转平台追缺口、缺口回补后死扛；
6. 探路尖兵不等缩量修正就进场；
7. 只看模型不看产业趋势/题材级别；
8. 没有止损——模型失效时以「再等等」代替纪律。
