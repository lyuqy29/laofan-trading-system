# 移动平均带：参数、趋势与三类买卖点

## 1. 参数

- **短期均线组**：5、8、13
- **中期均线组**：55、60、65
- **中枢**：60 日线（乖离率与趋势的分界）
- 均线周期取自斐波那契数列；可在日线、周线、60 分钟、15 分钟上同样设置。

## 2. 趋势判定：均线排列三态（先看这个）

移动平均带 = 短期组（5/8/13）+ 中期组（55/60/65）。三态只比较**两个组的相对位置**，不看单根均线：

| 状态 | 判定口径 | 成本 / 筹码含义 | 操作 |
|---|---|---|---|
| **多头排列** | 短期组 3 根**全部**在中期组 3 根之上（两组完全分层，无重叠） | 近两周买入者的平均成本高于近三个月买入者 → 中期持仓普遍浮盈，回踩有承接、拉高没有急抛 | **持股区**，顺势做多 |
| **空头排列** | 短期组 3 根**全部**在中期组 3 根之下（两组完全分层） | 短期成本低于中期成本 → 中期持仓普遍套牢，反弹到中期组附近就是解套抛压 | **远离**，不接反弹 |
| **缠绕 / 粘合** | 两个区间有重叠（均线互相穿插、走平，未形成完整上下分层） | 多空成本重新靠拢，筹码在换手，方向尚未选择 | **观察区**，不操作 |

### 2.1 三态的含义要点

- **多头排列是趋势的「结果」而不是「原因」**：它说明过去一段时间买盘持续强于卖盘、趋势已经走出来。此时买入是在赌趋势延续，所以必须同时给出止损位（跌破短期组减仓、跌破中期组清仓）。
- **空头排列下每次反弹都在「还债」**：价格向上碰到中期组就会遇到套牢盘解套，这就是「不接反弹」的技术理由，而不是情绪上的看空。
- **缠绕 vs 粘合（同一种状态的两个阶段）**：
  - **缠绕**：两组交织但带幅仍然宽，属于来回拉锯、多空都没占优；
  - **粘合**：六根均线明显靠近、带幅收窄到极限，是**变盘前夜**——重点不是猜方向，而是等一根放量 K 线（向上突破中期组 / 向下击穿）给出方向。
- **排列只是当下快照**：一根大阳或大阴就能把三态改写。所以判断要连看斜率：30—45° 健康、60—80° 加速（也意味着离调整更近）、走平走弱是转势前兆。

### 2.2 必须叠加位置

同一种排列，出现在不同位置，含义完全相反：

| 排列 | 低位 / 下跌末端 | 中继 | 高位 |
|---|---|---|---|
| 多头排列 | 反转成立，第一波试仓 | 主升途中，持有 | 加速赶顶，只减不加 |
| 空头排列 | 下跌末段，等企稳信号 | — | 趋势破位，清仓离场 |
| 缠绕 / 粘合 | 筑底换手，等方向 | 洗盘 / 中继整理 | 滞涨派发，警惕破位 |

### 2.3 与模型、打分的关系

- 六要素打分里的**「均线结构」这一票就是看排列**：多头排列给分；缠绕/粘合要降级（通常只能出弱化版）；空头排列基本不给分，模型形态再像也判失效。
- 九大模型都要求读「均线结构」这一要素，所以三态是模型的**前置条件**，不是并列指标。

### 2.4 看板里的实现

看板「位置与趋势」卡片上的**均线排列**就是这三个值，判定在 `dashboard/market.py` 的 `build_context()`：短期组整体在中期组之上 → 多头排列，整体在其下 → 空头排列，其余一律归「缠绕/粘合」。卡片同时给出位置判定、距 250 日高低点、5 日/20 日均量比与 BIAS60，正好对应本节的判断顺序。

判断顺序：先看位置（低位/高位）→ 再看排列（多/空/缠绕）→ 最后看斜率（30—45° 健康，60—80° 加速，走平转弱）。

## 3. 乖离率

`BIAS60 = (收盘价 − MA60) / MA60 × 100%`

- **负乖离 -20%～-30%**：第一类买点（乖离买点）触发区；
- **负乖离 -50%～-60%**：极端超跌，常见于筹码乖离修复模型；
- **正乖离 +30%**：震荡/熊市的阶段止盈阈值（等级二）；
- **正乖离 +50%**：牛市环境可放宽的止盈阈值；
- **正乖离 +100%**：极端主线龙头的「等级一」卖点。

大盘股的乖离阈值可适当下调（同样涨幅下更早触发）。

## 4. 三类买点（底部是复杂结构，分批进）

1. **乖离买点（第一类）**：下跌加速、负乖离进入 -20%～-30%，**试仓**。
2. **突破买点（第二类）**：**放量中阳线突破中期均线组**，加仓。
3. **回踩买点（第三类）**：突破后**回踩中期均线组不破**、再度放量启动，加仓。

> 三类买点不必全部出现；出现越多，仓位可以越重。买入必须与模型买点共振，否则只做均线买点、降低仓位。

## 5. 三类卖点（顶部同样是复杂结构）

1. **乖离极值**：+100%（等级一）/ +50%（牛市）/ +30%（震荡市）→ 部分止盈。
2. **跌破短期均线组**：多头动能衰竭 → 减仓。
3. **放量中阴跌破中期均线组**：趋势破位 → 清仓。

## 6. 与模型的关系

- 移动平均带 = **战略**（定趋势、定仓位、定止损线）；
- 九大模型 = **战术**（定具体买点）；
- 连板/加速股：以 **5 日均线**持股，有效跌破即走；出现天地板等极端走势要灵活处理，不机械等待均线。

## 7. 指标使用原则

- 不要堆指标：同类指标选一个，指标越多、出错概率越高（良率连乘）。
- 有效性较高的三个：**MACD**（趋势）、**布林线**（压力支撑）、**乖离率**。
- 指标只做**共振确认**，不单独作为买卖依据。

## 8. 多周期

- 日线定方向与买点，周线看背离级别（周线背离 → 反弹级别更大）。
- 60 分钟/15 分钟用于把日线买点「缩小级别」精确化，避免追高。
